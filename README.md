# Eye Reading Tracker

PDF 문서를 웹에서 렌더링하고, PDF Text Layer의 텍스트 좌표와 사용자의 시선 좌표를 매칭하여 사용자가 일정 시간 이상 바라본 영역을 자동으로 하이라이트하는 시선 기반 독서 보조 웹 애플리케이션입니다.

## 프로젝트 개요

본 프로젝트는 사용자가 PDF 문서를 읽을 때 웹캠 기반 시선 추적 기술을 활용하여 사용자가 실제로 바라보고 있는 텍스트 영역을 감지합니다.

PDF는 브라우저에서 렌더링되며, 각 텍스트 영역의 좌표 정보를 추출합니다. 이후 WebGazer.js를 통해 사용자의 gaze 좌표를 실시간으로 받아오고, 해당 좌표가 PDF Text Layer의 특정 텍스트 영역 안에 일정 시간 이상 머무르면 해당 텍스트 영역에 하이라이트를 표시합니다.

이를 통해 사용자의 읽기 흐름을 시각적으로 기록하거나, 집중도 분석, 시선 기반 독서 보조, 읽은 구간 표시 등의 기능으로 확장할 수 있습니다.

## 핵심 기능

### 1. PDF 렌더링

- PDF 파일을 브라우저에서 페이지 단위로 렌더링
- PDF.js 기반 PDF Canvas 렌더링
- 페이지 확대/축소 및 스크롤 환경 대응 가능

### 2. PDF Text Layer 좌표 추출

- PDF 내부 텍스트 레이어 정보를 추출
- 각 텍스트 요소의 위치, 크기, 텍스트 내용을 DOM 영역으로 관리
- 추출된 텍스트 영역을 시선 좌표와 매칭 가능한 형태로 변환

### 3. WebGazer.js 기반 시선 좌표 추적

- 웹캠을 사용하여 사용자의 시선 위치 추정
- 실시간 gaze 좌표 `(x, y)` 수집
- 브라우저 화면 좌표계를 기준으로 PDF 텍스트 영역과 비교

### 4. 시선 좌표와 텍스트 영역 매칭

- WebGazer에서 받은 gaze 좌표가 특정 text layer 영역 안에 있는지 판별
- `getBoundingClientRect()`를 활용하여 텍스트 영역의 실제 화면 좌표 계산
- 좌표가 포함된 텍스트 영역을 현재 주시 영역으로 판단

### 5. 일정 시간 이상 머문 영역 하이라이트

- 사용자가 특정 텍스트 영역을 일정 시간 이상 바라보면 하이라이트 표시
- 짧은 시선 이동이나 노이즈는 무시
- 읽은 영역, 집중 영역, 오래 머문 영역 등을 시각적으로 표현 가능
